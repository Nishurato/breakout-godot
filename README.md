# Breakout (Recreated in Godot)

Alright, I recreated game from The 20 Games Challenge to learn Godot. Recreate a Breakout. 

This time I don't added the menu, but I added a pause function and restart still there from Pong game. Yes, I reused assets from my version of Pong. Also I created new sounds and recreated old sounds for more juice. And I like that. This game supports a gamepad. That's all.
